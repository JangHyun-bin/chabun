# 녹음 예시

`voice-statement-ko-v1.wav`는 직접 작성한 아래 문장을 ElevenLabs David로 합성한 시연 자료다. 실제 사용자 녹음이나 음성 인식 결과가 아니다.

- 문장: 정차 중 오른쪽에서 충격을 느꼈어요. 정확한 사고 경위는 확인 중이에요.
- 생성: active Creator 플랜, Eleven v4. 원고·생성시각·원본 해시는 같은 이름의 JSON에 기록했다.
- 형식: mono 24 kHz PCM WAV, 5.28초.
- SHA-256: `12854c2131bf6864192804a7624c634fd42e0775fb63bc100b7bb6165037a784`.
- 실제 마이크 모드는 이 문장을 사용하지 않는다. 음성 인식은 미연동이며 녹음 재생과 직접 입력을 제공한다.

[제공자 공개 이용 조건](https://elevenlabs.io/docs/help-center/legal/can-i-publish-the-content-i-generate-on-the-platform): 유료 기간 생성물은 이용 조건에 따라 상업·무기한 이용이 가능하며 Beta Services는 제외된다. API에서 모델은 Eleven v4로 등록됐고 Beta 표기는 없었으나 명시적 Beta 필드는 제공되지 않았다.
