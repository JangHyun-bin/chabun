# 검증 기록

검증 대상은 이 저장소에서 빌드한 `com.chabun.vehicle` Release APK입니다. APK·MP4의 최종 SHA-256과 영상 검사 결과는 [Release v1.0.0](https://github.com/JangHyun-bin/chabun/releases/tag/v1.0.0)에 실제 파일과 함께 제공합니다.

| 검사 | 결과 |
| --- | --- |
| TypeScript, 웹·native 번들, Release 서명 | 통과. debug 키가 아닌 단일 서명 인증서를 확인했습니다. |
| 브라우저 UX·접근성·상태 전이 | 509/509 통과. 라이트·다크, 큰 글자, 마이크·버튼 배치, IME·뒤로 가기·중단·재개를 포함합니다. |
| 저장·동기화·API | 43/43 통과, 448 assertions. 충돌·실패·재시도와 자료 검증을 포함합니다. |
| 시나리오·안내 음성 계약 | 17/17 통과. 상태 전이, 기관별 상태 구분, 안내 자산과 재생 구간을 확인했습니다. |
| 공식 Pleos에서 서명 APK 실행 | 11/11 통과. 오프라인 여정, 119 전화 화면, 직접 입력·수정·승인, 저장 후 프로세스 재시작, 라이트·다크를 확인했습니다. |
| 별도 Android 연결 | 실제 native QR 이미지 해독 → 양쪽 확인 숫자 대조 → 차량 승인 → 사진 3장 저장·3대상 명시 생략 → 차량의 사진 3/6 표시를 확인했습니다. |

## 환경과 한계

- 차량: 공식 Pleos Connect Emulator, Android API 34, 2560×1440. 휴대폰 경로: 별도 Android 15 에뮬레이터의 Chrome 124와 HTTPS 서버.
- QR은 실제 차량 화면의 이미지에서 해독했습니다. 실물 휴대폰 카메라로 QR을 스캔했다고 주장하지 않습니다.
- 보관한 사고 사진은 직접 작성한 시연용 도식입니다. 실제 사고 현장 사진이 아닙니다.
- 실차, 실물 휴대폰, 실제 119 발신·기관 접수·출동·예약은 검증하지 않았습니다. 안내의 안전성 승인이나 실도로 사용 적합성을 뜻하지 않습니다.
- 최종 영상의 원본 촬영 파일과 편집 프로젝트는 MP4와 구분하여 비공개로 보관합니다.

재현 명령과 지원 범위는 [빌드 안내](build.md)와 [심사 시나리오](submission.md)를 참고하세요.
